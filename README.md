# 萤彩院色彩工作室 · Color Atelier

以鲜艳拼贴风呈现的图片提色小工具。支持整图配色分析、原像素精准吸色、收藏配色，以及面向 Photoshop 的 ACO / ASE 色板导出。

## 使用

1. 打开网页，点击「更换图片」选择本机参考图。
2. 自动提取 3～9 色；点击「吸色」可精确选取像素，气泡中的色号可复制。
3. 点爱心收藏；在「自动提色」或「我的收藏」中选择「导出色板」。Photoshop 优先使用 ACO，PNG 仅为预览。
4. 刷新恢复默认 LosYork 地图；收藏保存在当前浏览器的站点存储中。

## 数据说明

导入图片在浏览器内处理，不上传服务器；网站不保存用户的图片。收藏不跨电脑或浏览器同步，也不会自动读取本地 localhost 版本的收藏。清理站点数据可能清除收藏，重要配色请导出备份。

自动色占比是抽样估计，导出是 RGB 数值，不含 ICC 配置或透明度。不同文档颜色配置可能导致观感差异。网页是交互原型，尚未集成进正式桌宠程序。
